# BreadVale — Projeto demonstrativo

Conversão do conceito anterior em uma marca fictícia de panificação para uso em portfólio.

## O que foi mantido
- estrutura das páginas;
- paleta principal;
- grid e componentes;
- responsividade;
- filtros de produtos;
- mapa, formulários e CTAs como elementos demonstrativos.

## O que foi trocado
- toda referência à marca original;
- marca e favicon;
- história e slogan;
- endereço e mapa específico;
- Instagram e WhatsApp reais;
- catálogo de produtos;
- fotografias com embalagens/marca reais.

## Aviso
BreadVale é uma marca fictícia. O projeto deve ser apresentado como **projeto demonstrativo**, não como cliente real.
